# YOLOv11-S / MBV3 / MBV3-ECA（含ECA2）实验分析（可直接用于论文与答辩）

## 0. 结论先行（答辩可直接口述）

1. 你的训练流程中数据增强是开启且有效的，不是“没做增强”导致的结果偏差。
2. 验证集高分（Recall 0.89~0.91, mAP50 0.95~0.96）与测试集低分（Recall约0.26~0.30）之间的大落差，主因不是训练崩溃，而是跨年份农业场景造成的显著分布迁移（domain shift）。
3. 新ECA2确实解决了旧ECA参数量/FLOPs过大问题，并显著提升了mAP，但测试集Recall仍不高（约0.2835），说明“分类/定位质量变好”不等于“漏检问题已解决”。
4. 在不破坏原始消融公平性的前提下，优先做推理侧优化（阈值扫描、TTA、集成）；若要继续提高Recall，再单列“优化实验”做强增广微调或半监督。

## 1. 数据增强配置检查（基于args.yaml与训练脚本证据）

### 1.1 是否启用了增强

已启用。虽然 `augment: false` 出现在args.yaml中，但你显式设置了多项增强参数，且Ultralytics训练流程会实际使用这些增强项。当前应理解为：
- 你不是“零增强训练”。
- 你采用的是“受控增强策略”（固定关键增强参数，保证三模型公平对比）。

### 1.2 三模型（及ECA2）关键增强参数

来自各run目录args.yaml（YOLOv11-S、YOLOv11-S-MBV3、YOLOv11-S-MBV3-ECA、YOLOv11-S-MBV3-ECA2）：

- hsv_h = 0.015
- hsv_s = 0.7
- hsv_v = 0.4
- degrees = 8.0
- translate = 0.1
- scale = 0.2
- shear = 0.0
- perspective = 0.0
- flipud = 0.1
- fliplr = 0.5
- mosaic = 1.0
- mixup = 0.0
- copy_paste = 0.0
- auto_augment = randaugment
- erasing = 0.4
- close_mosaic = 10

这意味着你使用了：颜色抖动、翻转、旋转/平移/缩放、mosaic、随机擦除与自动增强策略；但未使用 mixup/copy-paste/perspective/shear。

### 1.3 增强是否不足的判断

不是“完全不足”，但对跨年域迁移而言偏保守：
- 已有增强主要提升常规鲁棒性。
- 对农业跨年变化（光照、作物冠层、杂草密度、土壤背景、拍摄距离/角度）仍可能覆盖不够。
- 因此会出现“验证集很好、独立年份测试掉点大”的现象。

## 2. 验证集与测试集巨大差距分析

### 2.1 你当前结果的客观事实

1) 训练分布内验证（results.csv第200轮）
- YOLOv11-S: Recall=0.9103, mAP50=0.9646
- YOLOv11-S-MBV3: Recall=0.9026, mAP50=0.9559
- YOLOv11-S-MBV3-ECA: Recall=0.8873, mAP50=0.9543

2) 独立2023测试（full200统一评测）
- YOLOv11-S: Recall=0.2657, mAP50=0.2155
- YOLOv11-S-MBV3: Recall=0.2971, mAP50=0.2406
- YOLOv11-S-MBV3-ECA: Recall=0.2974, mAP50=0.2501

3) 新ECA2四模型评测（2026-03-22）
- YOLOv11-S-MBV3-ECA2: Precision=0.4181, Recall=0.2835, mAP50=0.3450, mAP50-95=0.3229
- 相对旧ECA：mAP50 +0.0949，mAP50-95 +0.0990，Recall -0.0139，Params -1847246，FLOPs -4776253952

### 2.2 主因判断：域迁移为主，训练问题为辅

主因（占主导）：
- 训练/验证来自2021+2022，测试来自独立2023，本身就是跨年迁移任务。
- 农业场景受季节、降雨、土壤湿度、杂草生长阶段、作物遮挡、拍摄设备与作业路径影响极大，同一类别外观年际差异明显。
- 你已有记录显示test覆盖类别结构与训练分布存在偏差，这会进一步放大泛化差距。

次因（非主导但存在）：
- 模型在训练分布上拟合较充分，导致对“已见风格”非常好，但面对“未见年份风格”时召回下降。
- 目前增强策略偏向通用增强，针对跨域的风格扰动仍不够激进。

因此，结论更合理地写为：
不是训练失败，而是“分布外泛化不足”导致测试Recall大幅下降。

## 3. 新ECA2为何“结构更优，但测试仍不理想”

你这个判断是准确的，而且在论文里应当明确：

1. ECA2已经解决旧ECA的结构负担问题
- 参数量/FLOPs回落到接近MBV3量级，速度也明显恢复。

2. ECA2的精度指标明显变好
- mAP50/mAP50-95在四模型对比中最佳。

3. 但Recall没有同步提升，仍在低位（约0.2835）
- 说明模型“对已检测到目标的判别更准”，但“漏检问题”仍然严重。
- 在答辩中可解释为：注意力机制优化了特征表达质量，但无法单独解决跨年域偏移带来的召回损失。

可直接用于论文的一句话：
ECA2实现了“轻量化+精度提升”的结构目标，但跨域召回瓶颈仍受数据分布迁移主导，需通过推理策略与数据层优化进一步改善。

## 4. 不破坏原始消融公平性的Recall提升方案（按优先级）

说明：以下方案分为两组。
- A组：不改训练，只改评测/推理，不破坏原始消融主结论。
- B组：改训练或数据，必须作为“独立优化实验”单列。

### A1. 置信度阈值扫描（推荐先做）

步骤：
- 固定同一组权重与测试集，扫描 conf（例如0.05~0.5）与iou阈值组合。
- 以Recall优先选择阈值，并报告PR权衡。

预期效果：
- Recall通常可明显提升（代价是Precision下降）。

时间成本：
- 低，约1~2小时可完成并出图表。

公平性：
- 若所有模型使用同一搜索规则与评价标准，不破坏公平性。
- 建议作为“后处理优化实验”单列。

### A2. Test-Time Augmentation (TTA)

步骤：
- 在验证/测试阶段启用tta（多尺度/翻转推理）。

预期效果：
- 常见提升方向是Recall和mAP小幅上升。

时间成本：
- 低，约0.5~1天（含跑完测试与汇总）。

公平性：
- 不改训练，可公平比较。
- 作为“推理增强实验”单列最合适。

### A3. 模型集成（3模型或4模型）

步骤：
- 对同一测试图像融合多个模型预测（NMS Voting或WBF）。

预期效果：
- 往往可提升Recall与总体mAP，特别是错检互补场景。

时间成本：
- 中，约1~2天（需要实现融合脚本和参数调优）。

公平性：
- 不影响原始单模型消融结论。
- 应以“工程优化/部署优化实验”单独呈现。

### B1. 最优模型强增广短程微调（建议用ECA2）

步骤：
- 以ECA2为底座，增强跨域相关增广强度，进行短程微调（如30~60 epochs）。
- 保留原始full200结果不变，仅新增优化分支结果。

预期效果：
- 对跨年测试Recall有机会进一步改善。

时间成本：
- 中高，约1~2天/轮实验。

公平性：
- 会改变训练协议，不可与原消融表直接混排。
- 必须命名为“优化实验（非原始消融）”。

### B2. 半监督/伪标签（针对2023风格）

步骤：
- 用当前最优模型对2023未标注数据生成伪标签，筛选高置信样本回灌训练。

预期效果：
- 对跨域Recall潜在收益最大。

时间成本：
- 高，约3~7天（含筛选与多轮验证）。

公平性：
- 显著改变数据条件，绝不能与原始消融同表比较。
- 适合论文“扩展研究/泛化增强”章节。

## 5. 论文与答辩建议写法（可直接引用）

### 5.1 主实验结论（公平消融）

在统一训练协议下，YOLOv11-S、YOLOv11-S-MBV3、YOLOv11-S-MBV3-ECA（及ECA2扩展）均在验证集取得较高指标，但在独立2023测试集出现明显性能下降。该现象表明跨年农业场景存在显著分布迁移，模型跨域泛化能力仍是主要瓶颈。

### 5.2 ECA2结论（结构改进有效但召回未根治）

ECA2通过三点式注意力插入修复了旧ECA参数膨胀问题，在参数量、FLOPs和mAP上均优于旧ECA，但测试Recall未同步提升，说明结构优化提升了表示质量与精度上限，尚未彻底解决跨域漏检问题。

### 5.3 后续优化路线

后续应分两阶段推进：先采用阈值扫描、TTA与模型集成等推理侧策略提升Recall；再通过强增广微调与半监督域适配进一步缩小跨年分布差异。所有新增策略均作为独立优化实验报告，不回写原始消融结论，从而保证论文公平性与可审计性。
