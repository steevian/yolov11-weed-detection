# project2： 训练管理模块完善计划


### 1. 训练管理模块从占位到可用
文件：`yolo_weed_detection_flask/main.py`

已完成增强：
1. 增加训练运行态任务持久化：
	- 状态文件：`experiments/logs/train_tasks_runtime.json`
2. `create_train_task` 不再只占位，改为真实启动训练子进程。
3. `get_train_tasks` 支持：
	- 运行态任务（queued/running/completed/failed）
	- 历史 runs 自动扫描（`experiments/YOLO*`）
4. `get_train_monitor` 支持：
	- 真实读取 `results.csv` 轮次指标
	- 自动估计任务进度
	- 返回任务日志路径
5. `get_train_datasets` 支持真实目录扫描（`datasets`、`data`、`training/configs`）。
6. `get_train_dataset_analysis` 支持真实统计：
	- train/val 图片数
	- labels 类别分布（YOLO txt）
7. `get_train_model_compare` 优先使用真实 runs 指标进行对比。

前端同步优化（文案层，逻辑不改）：
1. `Train/ModelTrain` 去除“预留”文案与标签。
2. `Train/TrainMonitor` 去除“占位”文案与标签。
3. `Train/ModelCompare` 去除“占位”标签。

## 2. 当前可执行能力说明

### 2.1 检测能力
1. 图片检测：多类别 + 中文类别名 + 框。
2. 视频检测：逐帧多类别 + 中文类别名 + 框。
3. 摄像头检测：实时多类别 + 中文类别名 + 框。

### 2.2 训练管理能力
1. 可创建任务并启动训练。
2. 可查看任务列表与状态。
3. 可查看监控曲线与指标。
4. 可做数据集统计分析。
5. 可做模型比较（优先真实结果）。

## 3. 验收步骤（建议按顺序）

### 3.1 后端启动验收
1. 启动 `yolo_weed_detection_flask/main.py`。
2. 日志应出现：
	- 模型加载成功
	- 中文类别列表
	- Flask 监听地址

### 3.2 project1 三功能验收
1. 图像：上传含多类目标图片，确认表格和框标签均为中文。
2. 视频：上传视频，确认输出视频框标签为中文。
3. 摄像头：实时检测，确认画面框标签为中文。

### 3.3 训练管理验收
1. 在“模型训练”页面创建一个短轮次任务（例如 epochs=5）。
2. 在“训练监控”页面确认：
	- 任务状态变化（running -> completed/failed）
	- 轮次数据更新
3. 在“数据集分析”页面确认：
	- 数据集可选择
	- train/val 和类别统计可显示
4. 在“模型比较”页面确认：
	- 可选择模型并完成对比
